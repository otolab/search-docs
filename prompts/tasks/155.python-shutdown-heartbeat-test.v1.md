## 作業記録

- 短命な `python -c` でtimestampを直接書き換える構造をやめ、LA側のNode child processに通常の `DBEngine` APIでheartbeatを書かせる形に変更した。childをheartbeat失効まで生存させ、東京側のWatcherがfresh時にclaimせず、1秒の期限切れ後にtakeoverすることを実 LanceDB で検証する。
- `skipInitModel` 接続ではwriter heartbeat tableが初期化されないため、既存のDBEngine統合テストと同様にローカルhealth stubを立て、通常初期化で必要なtableとindexを作る。
- `uv python install 3.11.18` はこのホスト向け `cpython-3.11.18-macos-aarch64` の配布がなく失敗。ローカルではPython 3.11.13、macOS ARMで実施した。CIのLinux/Python 3.11.18とは同一条件でない。
- `uv sync --project packages/db-engine --python 3.11` で依存を準備。直接依存はpyproject.toml記載の固定版（LanceDB 0.30.2、PyArrow 22.0.0、NumPy 2.3.5等）だが、uv.lockがないため推移依存はこの日付の再解決結果であり、失敗当時のsnapshotではない。

### 調査と判断
