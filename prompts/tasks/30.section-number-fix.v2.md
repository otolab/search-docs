# Issue #30: セクション番号修正 - 詳細影響範囲分析

## 正しい仕様（再確認）

```
- document root (depth=0): sectionNumber=[]
- H1 (depth=1): sectionNumber=[1]
- H2 (depth=2): sectionNumber=[1, 1]
```

## 影響範囲の詳細分析

### 1. データ生成層（markdown-splitter.ts）

#### 修正箇所
**packages/server/src/splitter/markdown-splitter.ts: buildSections()**
```typescript
// 現在の実装
const sectionNumber = [...parentSectionNumber, i + 1];

// 修正後
// depth=0の子（つまりH1など）には空配列から始める
const sectionNumber = node.depth === 0 ? [i + 1] : [...parentSectionNumber, i + 1];
```

**注意**: extractHeadingStructure()は既に修正済み（空配列を渡す処理）

### 2. サーバーAPI層（search-docs-server.ts）

#### 影響箇所1: getOutline() - sectionIdフィルタリング (338-346行目)
```typescript
const targetSectionNumber = result.section.sectionNumber;
sections = allSections.sections.filter(s => {
  if (s.sectionNumber.length <= targetSectionNumber.length) {
    return false;
  }
  return targetSectionNumber.every((num, idx) => s.sectionNumber[idx] === num);
});
```

**空配列の場合の動作**:
- `targetSectionNumber = []`
- `s.sectionNumber.length <= 0` → depth=0以外すべてfalse（通過）
- `[].every()` → 常にtrue
- **結果**: すべてのセクションが含まれる ✅ 正しい動作

**修正不要**

#### 影響箇所2: getOutline() - OutlineItem変換 (374行目)
```typescript
number: section.sectionNumber.join('.')
```

**空配列の場合の動作**:
- `[].join('.')` → `""` (空文字列)

**問題**: MCPツールで`item.number`が空文字列になる
- get-outline.ts (95行目, 129行目): `${item.number}. "${item.heading}"` → `". "Title"` (不自然)

**修正必要**: サーバー側でフィルタリングしているので問題ないはず（depth > 0のみ）
→ **実際には修正不要**（depth=0は既に除外されている）

### 3. MCPツール表示層

#### 影響箇所1: get-document.ts (100行目, 153行目)
```typescript
const sectionPath = response.section.sectionNumber.join('-');
resultText += `Level: ${depthLabel} | Section: ${sectionPath} | ...`;
```

**空配列の場合の動作**:
- `[].join('-')` → `""` (空文字列)
- 表示: `Section:  | Line: ...` (空白)

**問題**: document rootをsectionIdで直接取得した場合に表示が不自然

**修正方法**:
```typescript
const sectionPath = response.section.sectionNumber.length > 0
  ? response.section.sectionNumber.join('-')
  : 'root';
```

**修正必要**: ✅

#### 影響箇所2: search.ts (133-141行目)
```typescript
const hierarchy = formatSectionNumber(result.sectionNumber);

if (hierarchy) {
  resultText += `📄 「${heading}」(${hierarchy})\n`;
} else {
  // depth=0の場合は章節項号なし
  resultText += `📄 ${heading}\n`;
}
```

**空配列の場合の動作**:
- `formatSectionNumber([])` → `""` (空文字列)
- `if (hierarchy)` → false
- **結果**: 正しく処理される ✅

**修正不要**

#### 影響箇所4: get-outline.ts (95行目, 129行目)
